1. <span style="color:rgb(255, 0, 0)">mouseover </span>
		会冒泡，鼠标进入子元素时也会触发
2. <span style="color:rgb(255, 0, 0)">mouseenter </span>
		不冒泡，只有进入真正目标元素（不包括其子元素）时触发
3. <span style="color:rgb(255, 0, 0)">mouseenter</span> 
		与mouseleave 配对使用
4. <span style="color:rgb(255, 0, 0)">mouseover</span>
		与mouseout 配对使用
