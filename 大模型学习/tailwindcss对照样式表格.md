| 横向排列   | `flex items-center gap-2`     | 最常用组合                     |
| 纵向排列   | `flex flex-col gap-4`         |                           |
| 水平垂直居中 | `items-center justify-center` |                           |
| 内容限宽居中 | `mx-auto max-w-2xl`           |                           |

| 边框     | `border border-zinc-200`      |                           |
| 阴影     | `shadow-sm`                   |                           |
| 文字大小   | `text-sm` `text-lg`           |                           |
| 字重     | `font-medium` `font-semibold` |                           |
