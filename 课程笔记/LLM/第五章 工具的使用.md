### 工具传入参数的优化
#### 方法一：pydantic
| 组件                                   | 作用                 |
| ------------------------------------ | ------------------ |
| `BaseModel`                          | 定义数据模型的基类          |
| `Field`                              | 给字段加约束（默认值、范围、描述等） |
| `ValidationError`                    | 校验失败时抛的异常，含详细错误位置  |
| `model_dump()` / `model_dump_json()` | 序列化成 dict / JSON   |
示例：


```from pydantic import BaseModel, Field

class **Query**(BaseModel):
    city: str = Field(description="城市名称", min_length=1)
    top_k: int = Field(default=5, ge=1, le=20, description="返回条数")
    unit: str = Field(default="celsius", description="温度单位")
    
 @tool(args_schema=Query)  
 def getCitys(city:str,top_k:int,unit:str) :```



```
补充：
	Field使用：
		**description**:  字段说明（这个在LangChain里会进JSON Schema,是写给模型看的）
		**default**：默认值
		**ge/le/gt/lt**   数据范围
		**min_length/max_length** 字符串长度
		**pattern** 正则
		**alias**   外部字段名映射

#### 方法二：docstring 

示例：
parse_docstring必须设置为True，Args下面加参数描述，不过不像pydantic那样灵活，可以设置更细节
```
@tool('get_weather_and_forecast',parse_docstring=True)

def get_weather1(city:str,if_forecast:bool):

    """

    获取指定城市当前的天气，可以包含明日的天气预报

  

    Args:

    city: 城市名称

    if_forecast: 是否包含明天的天气

    """

    res = f'{city}天气晴朗'

    if if_forecast:

        res += '\n可能有零星小雨'

    return res
```
